# Restore archived Buddy data in Manager

Source and required Windows/Linux development and retained-package qualification are accepted at Manager `fa144e094e41f0a263cc3460b2fef19281767978`. These checks use synthetic transport/auth responses; they do not establish physical tablet, native-page or running Buddy health. Final coordinated merge and actual-main release verification remain separate delivery gates.

Both companions offer **Restore an archive already on this tablet**. Enter its full tablet path and choose **Preview restore**. The preview explains how the archived Buddy data is added while current records are kept, whether all media is available and whether saved settings are included separately without being applied. Exact counts are available under optional technical details. Review it, then choose **Confirm restore** deliberately. No automatic confirmation or retry occurs.

The archive must already be on the wired tablet, and supported Buddy data must already exist there. This does not download a backup, initialize an empty/replacement tablet or restore native pages. Saved settings/credentials are not activated and running Buddy/native pages are not checked. Unsupported, corrupt, oversized or conflicting data refuses rather than pretending the tablet is ready.

If the earlier result is unconfirmed, use **Check this restore**. A later check finding the expected data does not confirm or change the earlier restore result. A check not finding it does not prove the earlier changes were undone. An attempt stopped before updating current data is different: temporary files may remain, with no automatic cleanup or retry. Earlier attempts remain visible while a genuinely new restore may be previewed within bounded room, without renewing or replacing an old one.

The submitted path clears from the draft and actual DOM before the first admitted wait, and is not saved or shown in a result. **Stop restore wait** affects only its captured wait/operation, never undoing past publication. Before the host reference is known it is local detachment; the archive check can still finish. Previews expire after two minutes, private original checks after at most thirty minutes without renewal. Eight retained row slots (expired rows use their individual slots) and thirty-two executing invocation entries per original are finite; no eviction or reconstruction follows from expiry/restart/full capacity. **Show earlier restore attempts** reads host memory only.
