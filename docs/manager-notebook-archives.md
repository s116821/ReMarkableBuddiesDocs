# Notebook archive companion controls

The paired Manager change adds explicit ordinary format-4 notebook export and detached inspection in browser/helper and Electron. Use the [Manager guide](https://github.com/s116821/ReMarkableBuddiesManager/blob/main/docs/notebook-archives.md) for manual commands, exact private paths, optional saved-configuration inclusion, on-tablet location and bounded history/uncertainty.

The central [consumer contract](../openspec/changes/manage-notebook-archives/contract.md) fixes the closed protocol and original custody. The [producer contract](../openspec/changes/archive/2026-11-04-expose-notebook-archive-maintenance/contract.md) remains owned by the backend. Consumer qualification and source revisions will be recorded in the paired change results; planned checks are not physical tablet or released-feature evidence.

A known producer refusal means no export writes began, not that the command never launched. A matching success report needs successful exit and current identity. Explicit later inspection observes current complete closure only; it cannot settle the original publisher. No retry, overwrite, cleanup, restore, transfer, mode change or runtime activation is implied.

The independent Manager base preserves delivered storage and test-asset staging. Native Stop is a separate, unqualified lane; its owner reconciles this new peer after consumer integration. No Stop enablement is bundled or required.
