# ReMarkableBuddies

One Rust tablet application for Reader and Writer, with an Angular browser and Electron companion. This public hub is the **sole home of all OpenSpec specs, active changes, archives, config and workflow skills**.

Start with [contributing and setup](CONTRIBUTING.md), [architecture](docs/architecture.md), [public roadmap](docs/roadmap.md) and [OpenSpec workflow](openspec/README.md). [Canonical specs](openspec/specs) describe as-built behavior; [active changes](openspec/changes) are unfinished plans.

The [repository manifest](repositories.json) owns repository roles, URLs, public issue/PR routes, checks and independent release sources. Run `python scripts/workspace.py` to display it without cloning anything.

| Repository | Responsibility |
| -- | -- |
| [Docs](https://github.com/s116821/RemarkableBuddiesDocs) | Public requirements and all OpenSpec/workflow assets |
| [Rust](https://github.com/s116821/ReMarkableBuddies) | Unified Reader/Writer tablet application |
| [Manager](https://github.com/s116821/RemarkableBuddiesManager) | Shared Angular browser and Electron companion |

No private board, reference repository, plugin, editor or tablet is required to contribute. See [source provenance](docs/migration/README.md) and [licensing](docs/licensing.md).
