# Closed archive inspection/export consumer contract v1

## Authority and wire
This is a proposed consumer contract, not existing producer Prepare authority. Fixed producer selectors are `--archive-operation inspect|export-selected --archive-input -`; fixed configuration `/home/root/.config/remarkable-buddies/config.json` is selected only by the existing private fixed environment. Each invocation uses only exact UTF8 JSON `{path:ABSOLUTE_TABLET_DIRECTORY}` on stdin. Never interpolate path into shell/argv, accept renderer config/command, open a Buddy service or use WLAN product management. Existing producer safe paths, owned roots, selected-aware Store/mode/process custody and integrity checks remain authoritative.

Private input/report <=16384bytes including JSON whitespace/newline; private envelope <=24576; stderr <=8192 and never surfaced raw. Public initial path request <=16384, other requests <=512 and public result <=8192. Scalar path UTF8 <=4096, starts `/`, is not `/`, has no NUL, and is not trimmed/normalized; preserve escaped CRLF/trailing characters exactly. Local validation is not filesystem safety. Reject malformed UTF8/BOM, duplicate keys at every depth, extra keys, nonfinite/nonsafe integers, trailing data, invalid base64 or mismatched observation. Exactly one producer JSON line ending one LF, no embedded physical newline/extra report; harmless JSON spaces within that line are admitted. Helper command8seconds within transport12/host13/UI14 absolute monotonic deadlines; existing caller EOF/cleanup semantics. No assertion/timeout inflation.

Private envelope keys exactly selector,input_base64,budget_ms,connection_id,boot_id. selector is inspect/export-selected, budget_ms integer1..12000 bounded by remaining deadline; connection_id lowercase64hex; boot_id canonical nonnil UUID. Fixed action `selected-archive` and private raw reply `archive_raw` mirror existing closed transport envelopes: contract_version1/status/observation/archive_raw, archive_raw exactly status/stdout_base64. Only reported current-identity stdout can be parsed; other transport outcomes cannot become successful archive data. The implementation must add only these explicitly named surfaces, not dynamic routing.

## Host lifecycle and ownership
Prepare-export is only a local consequence preview, no producer dispatch/counts/source lock/receipt. It captures verified last observation/path, reserves bounded room, and returns a120second ready reference. It cannot guarantee export or a frozen source. Confirm requires that exact ready context and nonexpired identity. Under the shared owner, before possible dispatch: revalidate captured context and exact privately hashed input/path bytes, consume the ready grant once, retain immutable original input/destination and history, start nonrenewing30minute private-custody deadline, then invoke export-selected once. Export ok records exported/partial-media; failed/missing/truncated/nonzero/mismatched/late output after possible dispatch records unknown. Valid invalid-input/unavailable/unsupported/busy reports are known not-dispatched under this exact producer implementation. No second export follows any consumed original, including new invocation IDs.

Check-export requires that retained exact original, unexpired custody, current matching original connection/boot and a fresh invocation. Verify independent input/path custody hashes and reparse before deriving inspect input from the ORIGINAL path only. It calls inspect only. Success reports readable custody at that path now; never changes original outcome, proves original publisher, compares against a nonexistent producer digest or calls export. Invalid/missing/corrupt/unsupported/failed check stays unresolved/unavailable with historical result intact. A later valid archive may be unrelated; never label original uncertainty confirmed. No automatic refresh, source reprepare, retry, overwrite or cleanup.

At most8original rows including expired metadata plus one ready reservation within the same8slot budget; no eviction.
