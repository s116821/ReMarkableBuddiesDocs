## Why

Reader currently retains source images and a selection center, but not a bounded
interpreted subject, durable current target or visible About confirmation. Writer
cannot prove circled-only source scope or keep its export identity distinct from
page/notebook notes. This change connects real Reader interpretation, historical
receiving and stored-target Writer through the existing application.

## What Changes

Add exact source-target/use/state and regional-source records; prepare one closed
target-capable generation family through supported startup; persist interpretation
with the real Reader transaction; inherit/correct/retarget explicitly; render About
through actual answer serialization and historical projection; normalize an exact
original-frame region through the existing handwriting path, then generate,
refine and export a target-scoped Writer note through the existing command/flow.
Preserve selected closure, compatibility, original-only recovery and bounded
request ownership. No second recognizer, export backend or runtime service.

## Impact

Unified Rust application and central storage, Reader, conversation, layout,
Writer/export and simulator contracts. Integrate the frozen Reader, retained
resident-history and reviewed handwriting interfaces; independent predecessor
checks do not qualify the combined tree. This remains one unfinished pre-1.0
feature. Native About/output, scope gestures/Submit, selected regional Writer
input and live handwriting/device quality remain acceptance obligations where
not supplied by the initial ordinary stored-target route.
