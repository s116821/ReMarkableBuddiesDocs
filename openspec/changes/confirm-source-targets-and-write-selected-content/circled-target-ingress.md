## Private adapter and phase contract

Keep the current public capture request shape and its numeric-page refusal intact.
Add a typed target request on the existing Writer/conversation-operation dispatch,
reusing GenerateTarget identities and exact selection/root wire evidence. Proposed
`WriterGenerateTarget` is a value on the current conversation-operation adapter,
not a separate service/CLI process; existing capture request encoding stays valid.
The target reference resolves only against the exact selected closure. Do not call
the ordinary Ledger lookup on a selected route or fill omitted active media from
retained/ordinary/cache bytes. Do not serialize a live token or a boolean saying a region is already verified.

Internally generalize the selected image continuation's source proof to capture
or regional input. A regional factory runs under the existing ordered document
admission and constructs the private proof from the exact selected closure; callers
cannot construct it from raw masked bytes. Its locked check revalidates target,
source/media/geometry and current root/token. It does not require a fictitious
native numeric page: logical region unit1 is distinct from optional historical
native page identity. The original capture variant keeps its existing validator.

The shared runner accepts the owned source proof, original preference lifetime,
frozen handwriting context and the existing memory view. It still uses one-use
normalization/draft stage counters and `with_document_phase` for source,
preference, correction/checkpoint and applicable memory custody. Recheck and
commit remain in the same joined callback; no after-response check followed by an
ordinary Writer call or raw activate bypass is permitted. Gates do not span model
response waits. Metadata discovery is not image admission.

Before any possibly costly target-understanding or normalization submission,
persist the existing style of Prepared/original receipt using deterministic
`stage(operation, purpose)` IDs. Distinct child stages must preserve Store-wide
operation uniqueness. A known own interpretation commit may advance the frozen
root/token only through its returned receipt, never an arbitrary fresh snapshot.
No lost acknowledgment or restart repeats a model call or replenishes an original
allowance. Historical inspection/recovery reports evidence, not a new live permit.

Both capture and regional inputs recognize the two historical normalization-child
purposes for one parent operation. First preparation checks parent and both children
for accepted local evidence atomically under the Store mutex, using the original
phase allowance. These absence checks create no long-lived parent reservation.
Immediately before stage-0 submission, recheck the exact child token and parent
absence under that mutex while retaining the outer joined source/policy/context
gates. Invoke only the existing immediate worker-spawn callback there; release the
mutex before waiting for a model response. Stage1 instead retains its acknowledged
parent preparation and never requires that its own parent be absent.

## Budget and effect boundary

For the new regional operation, retain one monotonic start and original300s parent
(ordinary export345s). Its cutoffs are fixed offsets from that same start:
admission60s, normalization150s, draft240s, final proof/publication300s. Target
identification has at most45s and is further clamped to remaining admission.
Normalization and draft retain at-most90s provider caps and also get only the
remainder of their fixed slot. A delayed stage never receives a renewed timeout.
Existing capture-route timing semantics are unchanged.

Every source/policy/context reread and final proof spends the original partitioned
read allowance. No new policy owner follows interpretation. Deterministic budget,
slot-expiration and cancellation controls must enter the actual regional adapter.
If a derived mask matches an already frozen example, refuse rather than drop or
reselect examples after first model use. Only an acknowledged own receipt can
advance target/root correspondence. These bounds and file ownership were accepted
by the coordinator before runtime edits; there is no outstanding timing-policy
proposal for this increment.

The publication boundary also spends that same allowance for locked history,
operation inventory and full selected/retained closure validation. A time/cancel
callback checks after taking the Store mutex and after staging/syncing the head,
immediately before marker rename. It must neither re-enter Store nor acquire a
domain gate. Refusal before a marker attempt publishes nothing; a possible marker
attempt retains exact-head/original-receipt reconciliation. Exceptional whole-Store
integrity recovery is distinct from pre-publication request proof and is not claimed
to fit that request allowance. Capture keeps its established60s admission/300s
parent, with no regional150/240s stage allocation added to it.

The ordinary route keeps its existing deliberate draft/refine/export choices.
The current selected runner is Generate/Refine data-only; this adapter grants no
native output or selected export authority. Those missing effect routes remain
explicit full-feature obligations, not reasons to call the regional input done.
An installed fresh gesture needs current admitted source identity; a historical
reference alone never authorizes native page mutation, erasure or page recreation.
Preserve the question-only erasure convention without erasing the circle,
highlight or source annotations. Ineligible legacy LocalOnly selected history
keeps its delivered ordinary route and is never silently re-rooted to enable this
scope. Eligibility/currentness/media failure must not fall back to a broader scope.
