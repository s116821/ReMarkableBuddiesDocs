## Why
Both companions inspect saved storage mode and personalization, but lack a bounded
view of the saved general configuration. A raw Config dump can expose arbitrary
strings and private identities, while saved settings alone do not prove runtime,
provider or root state.

## What Changes
- Add explicit saved-configuration inspection in the shared browser/Electron UI,
  using the exact producer contract accepted at2a320181.
- Validate/reduce the private report into the exact25-field scalar/presence view,
  preserving default/declared/null origins and explicit unsupported settings.
- Integrate before-I/O prepared-forget invalidation and host/controller generations,
  including same-ID refresh/navigation and serialized cancellation.
- Verify attributed actual producer specimens, real protected host paths and
  ordinary Linux/Windows retained packages in one coordinated delivery.

## Capabilities
### New Capabilities
- `manager-saved-configuration-inspection`: explicit bounded saved-only view,
  private reduction, session lifetime and paired verification.

### Modified Capabilities
None. Existing personalization, saved-mode and forget contracts keep their authority.

## Impact
Manager host/parser/transport, optional bridge, shared controller/panel, public guide
and feature checks; central own consumer change. No provider/model-credential access,
settings writes, effective configuration resolution, path admission, service/native
work, new persistence/dependency or source-maintained release version. Main owns
all producer implementation. This is precode, not an implemented capability.
