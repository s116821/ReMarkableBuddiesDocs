Use existing Rust1.98.1 client/reqwest0.13.4/rustls0.23.45/platform-verifier0.7.1 and Python3/OpenSSL already available on Linux. No new package or trust override in production code.

A private UUID temporary root holds freshly generated CA/alternate-CA/server keys, correct and wrong-name leaves, empty root directory and ready/stop/result/child-witness files. Generated keys never enter Git/logs. Python binds only127.0.0.1 and permits CONNECT only to its exact owned origin ports. Origin validates bounded synthetic POST/body/auth and emits booleans/counts, never request headers/keys. The parent invokes the actual client in a separate test child with cleared proxy variables, explicit SSL_CERT_FILE/SSL_CERT_DIR and selected HTTPS_PROXY/NO_PROXY values. No process-global environment mutation, OS trust-store install, host DNS/proxy change, real provider request or native action.

Require invocation-specific child nonce completion and provider handshake/request/proxy witnesses; exit0 alone is insufficient. Use monotonic bounded polling only for ready/exit/stop files and child state; elapsed time is not proof of TLS or routing. Always stop and wait/kill owned children before deleting only the marked root. Missing Python/OpenSSL fails the Linux qualification instead of silently passing. Other OS builds may compile the unchanged client but are not qualified by these Linux-only cases.

Cases: trusted root/correct IP success; unrelated valid root rejects before application request; trusted root/wrong IP rejects; HTTPS CONNECT succeeds with proxy credential separate from origin auth; NO_PROXY bypasses an otherwise configured proxy; unrelated root still rejects through CONNECT. Actual server/context positive controls prevent treating a broken TLS fixture as successful rejection. Controlled process root input is not native OS store, provider trust policy, external DNS, platform system proxy, tablet latency/cancellation, billing or export qualification. No second network/cancellation engine is introduced.

Source basis: current pinned crate implementations (platform verifier verification/others.rs, rustls-native-certs environment paths, reqwest ProxyMatcher and hyper-util environment matcher), local tool inventory and current REM40 requirements.
