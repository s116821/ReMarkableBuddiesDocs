# Why
Running Manager views show stable candidates, but the accepted real-byte bundle downloader remains a manual command. Both distributions need explicit verified download without pretending they can activate an update.

# Scope
Reuse the fixed Manager quarantine consumer behind host-owned download/status/cancel actions. Keep trusted interpreter/download parent in host setup and caller input to a stable tag. Show actual completion versus partial/refused/cancelled, with explicit no-update eligibility. Package the existing trusted verifier and qualified producer code. No tablet/backend/release/payload execution or extraction.
