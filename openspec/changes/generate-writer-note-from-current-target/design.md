## Context

Stored-target Writer already validates original capture custody, masks the exact regional source on the original canvas, normalizes it and persists a scoped Writer draft. Its exact-reference JSON command remains useful to callers that deliberately select a historical target.

## Decision

Use a separate typed value in the existing installed Writer slot, named `generate-current-target-on-tablet`. The existing release and capture select a matching unexpired request. A foreign or expired regional intent refuses that release. Ordinary Reader and previously supported refinement retain their existing routing. The selected fresh-region receiver keeps its separate scope. Its shared peek preserves a live ordinary request and refuses the release. On expiry it retires the request under the same lock, still refuses that release and lets the next release select Reader.

Resolve the conversation from the binding for the observed current page or its verified adjacent Buddy page. Capture the conversation revision before resolving the immutable current target use and require an interpreted region from the binding's original resident document and page. The existing runner verifies the retained frame and guards publication against intervening changes. A missing binding, missing region or uncertain target refuses before model work.

Return the generated draft through the existing guarded Writer presentation path. It checks the exact root, source and prior binding before submitting; the saved draft and regional provenance also support the existing refinement and export preparation. Reuse the request's explicit operation ID and durable no-replay boundary. The native composer owner must still turn a user submission into this typed intent.
