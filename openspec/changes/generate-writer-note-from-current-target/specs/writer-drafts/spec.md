## ADDED Requirements

### Requirement: Ordinary Writer generates a draft from the current saved selection

The ordinary installed Writer receiver SHALL accept an explicit current-target request through its existing activation-bound slot. A matched release SHALL resolve the observed page's existing bound conversation and its exact current interpreted target on the binding's original resident source page. Writer SHALL use the guarded stored-target mask and draft workflow. Unavailable targets and nonmatching requests SHALL refuse without a model request or fallback to Reader or a wider source scope.

#### Scenario: Generate a note from a saved marked region

- **WHEN** the admitted Writer request matches the observed page and its bound conversation has a current interpreted target on the retained source
- **THEN** Writer normalizes the existing mask and saves one draft in that conversation with the same regional provenance
- **AND** the existing Writer placement path presents the saved draft and its source description under current binding and native output checks

#### Scenario: Target is unavailable or changed

- **WHEN** the slot or target cannot be matched to the current bound source before preparation
- **THEN** Writer refuses before model work and preserves the receiving rules for an ordinary release with no pending Writer request

#### Scenario: Continue a regional note

- **WHEN** the user refines the returned draft or prepares it for export
- **THEN** the existing commands keep the exact original regional scope
