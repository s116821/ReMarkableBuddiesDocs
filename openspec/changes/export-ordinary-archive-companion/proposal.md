# Shared ordinary archive export on the tablet

## Why
The delivered ordinary export producer is not exposed by either companion. Existing read-only inventory cannot create a recovery archive. This increment exposes explicit original-bound creation and reconciliation in both browser and Electron; it does not claim an off-device backup.

## Scope and ownership
Manager-owned optional protected host operation, safe count preview and separate confirmation UI over the unchanged ordinary export producer. Exact destination goes through stdin only; private original destination/intent stays bounded in host memory. No restore, transfer/download, provider, service, mode, initialization or credential change. Main retains all source producer ownership.
