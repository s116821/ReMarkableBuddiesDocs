This is the still-unimplemented companion portion of the accepted basic-settings plan, retained separately so the completed producer can be delivered incrementally. It does not add scope or claim that a shared editor exists. SCRAPPY owns browser/Electron host and UI implementation; Main owns the producer and Root coordinates review.
