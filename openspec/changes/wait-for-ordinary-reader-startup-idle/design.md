## Boundary

The startup path may abandon read-only admission when a valid input observation reports activity. Continue polling the same observer for quiet input, with the original startup deadline and the main-thread health check. Open a fresh guard for the next read-only attempt. Recheck the existing admission before publication. The prior canceled guard supplies no authority to the new attempt.

Classify input activity explicitly at the read-only boundary. Activation publication and every later phase use the existing strict input guard and recovery path. Input integrity loss, an occupied slot or an unrelated admission failure stops startup.

Log the first idle wait without logging input details. Existing activation completion continues to indicate Reader can start listening.
