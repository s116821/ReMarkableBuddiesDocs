For an explicit request, generate the draft through the installed current-page receiver. Reuse configured destination and actor admission, the existing exact-draft export flow and its readback/recovery behavior. Derive the ordinary save identity from the observed source document and page. Use a stable conversation for that source until a verified Buddy page is bound. Reuse the earlier applicable default correlation from the owned conversation when it already has an export association for this destination. Preserve the existing recovery path for uncertain writes. If the same source correlation already belongs to another conversation, do not start a second export from a different conversation. A failed or refused placement leaves the existing destination association available on a subsequent gesture. An explicit request for a separate note derives a distinct correlation from the admitted submission. Derive the invocation IDs from the admitted submission so a consumed event cannot issue another write. Check source ownership and the draft before export, including the final write gate. Use the existing guarded Buddy-page placement to present the request, draft and result. If the full text fails the existing page or new-page text check, select a compact outcome before placing any text. The full draft stays in history, and verified or uncertain effects stay in the existing export association. Text selection and any presentation retry use the saved result without dispatching another write. Describe uncertain outcomes as needing reconciliation.
