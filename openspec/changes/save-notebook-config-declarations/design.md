## Existing wire, custody and uncertainty
No member, version, selector, request or report changes. Basic keeps embedded changes in its original intent; model/memory keep separately verified canonical patch fingerprints. Original operation/path/base/target/CAS conditions remain, including no-change and stale/altered-intent refusal. Preserve status/outcome mapping: possible publication stays unknown, Refused/Conflict keep their existing family semantics, and Status only observes original desired bytes without replaying or regrading history.

All three retain basic::Custody's Arc/ordinary-or-explicit mode lease in the consuming report through write_all/error; do not add a flush call or release custody early. Basic/model success remains verified disk readback plus restart-required; memory success remains verified disk readback plus runtime unverified. Model values and memory profile identities remain private presence/origin summaries, not echoed strings/IDs. Other raw declarations, notebook data, identity/current/contract/capabilities/media and staging remain unchanged. Existing trusted/quiescent filesystem and durability limits remain.
