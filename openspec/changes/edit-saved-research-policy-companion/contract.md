Use existing64lowerhex connection_id/reference, nonnil canonical boot UUID and fresh observed matching device identity. ## Safe response and public phase matrix
Response is existing ObservationResult plus exactly research_settings:{state,reference,current,report,retained}. FIELDS is exactly {research_policy:{origin:"default"|"declared"|"declared-null",value:"required"|"disabled"}}. Default and declared-null require value required; declared permits required/disabled. Origins are not interchangeable. No raw config/path/file bytes/digests/private intent/patch/arbitrary errors appear in public output.

report is null or exactly {operation:inspect|prepare|apply|status,status:ok|invalid-input|unsupported|unavailable|busy|conflict|failed,outcome:read-only|no-change|verified|desired-file-observed|unresolved|not-dispatched|unknown,disk_readback_verified:BOOLEAN,runtime_activation:"unverified"}. Prepared is private intermediate authority, never a public editor result. retained is at most8 unique {reference,connection_id,boot_id,state:unknown|unresolved}, with no process-restart persistence guarantee.

Finite states: none,ready,invalidated,unsupported,unavailable,busy,capacity,not-dispatched,no-change,verified,unknown,unresolved,desired-file-observed. Begin permits ready/invalidated/unsupported/unavailable/busy. Save permits verified/no-change/not-dispatched/unknown/capacity/unavailable/busy. Status permits desired-file-observed/unresolved/unknown/unavailable/busy. Cancel permits not-dispatched/unknown/unresolved/invalidated/unavailable. Retained yields none with unconfigured/null observation, null reference/current/report and no remote I/O.

Only ready/no-change/verified/desired-file-observed expose nonnull current, with observed matching identity/reference and the corresponding successful inspect/read-only, prepare/no-change, apply/verified or status/desired-file-observed report. Only verified has disk_readback_verified true; all reports require runtime unverified. Unresolved requires successful status/unresolved/false, retained original and null current. Unknown requires a possibly dispatched retained original, null current and null report or apply/failed/unknown/false. Identity/reference mismatches refuse before updating UI/retained state.

Refusals expose null current/false readback. Begin unsupported maps unsupported; Busy maps busy; other inspect refusals unavailable. Prepare refusals map not-dispatched. Apply proven pre-dispatch refusal maps not-dispatched; possible/malformed/truncated/late result maps unknown. Status refusal maps unavailable/busy and never removes or settles earlier uncertainty. Cancel cannot fabricate producer success. A future desired-file observation may retire the reconciliation handle but cannot rewrite historical publication claims.
