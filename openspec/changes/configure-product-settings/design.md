## Decisions

Use a dedicated inspect/prepare/apply/status capability with fixed wired command
and private bounded stdin followed by EOF. Keep basic-v1 frozen. Unknown schemas,
unsupported selectors and invalid shapes refuse; no raw configuration fallback.

Inspect communicates saved declarations/origins, not effective running state.
Only genuinely changed supported fields enter an original CAS patch. Clearing
one declaration preserves siblings and unrelated/unknown configuration. Absence
retains the established enabled/enabled/Mem policy without writing a default
object merely to inspect it. Exact object/null/default semantics must be frozen
with the producer before code, not independently chosen in each repository.

Saving verifies disk readback only. No automatic retry, rebase, service restart,
provider call or silent credential/environment precedence change follows.
Prepare/apply/status bind the original config path, source bytes, private change
digest, target bytes and operation. A lost reply can remain unknown; later desired
file observation does not prove historical authorship, rollback or activation.

Maintenance remains available with roles/export disabled and before credential
resolution, permitting re-enablement. Reader-off/Writer-on cannot accidentally
start the ordinary Reader loop. Writer refusal covers explicit and Reader-routed
Writer entry points. Disabled export refuses new dispatch; existing original
uncertain/historical reconciliation remains separately available and cannot mint
a replacement operation or grant a new dispatch. Turning settings off deletes
no data or third-party note.

Both hosts share a controller/panel with explicit Begin and deliberate Save,
exact original-response binding, immediate draft/DOM clearing and safe errors.
The new maintenance owner must preserve all210 existing directed pairs; sixteen
owners require240 ordered grant/Busy relationships. Enumerate actual App peer,
observation, cancel, identity and page lifetime paths, not just private hooks.
Stop revokes an unconsumed ready grant permanently, including a delayed action
after any short arrival fence, without revoking a newer grant or implying
rollback of a possibly dispatched save. Custody/deadline/capacity are finite and
nonrenewing; exact values and wire bounds await the shared freeze.

## Limits and alternatives

Mem/Disabled selects the existing backend only. It supplies no configured
account/workspace/collection/note identity, arbitrary URL or new credential key.
Those requirements remain open where not covered by existing contracts. Existing
credential editors remain separate. A second sync engine, generic raw editor,
a guessed schema and direct running Buddy API are rejected.

No local save or host fixture proves running Reader/Writer adoption, native page
readiness or live provider behavior. Runtime activation/restart and integrated
qualification remain explicit later acceptance, not reasons to block host work.
