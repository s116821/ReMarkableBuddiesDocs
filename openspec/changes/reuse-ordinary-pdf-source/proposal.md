## Why

Asking a second question about the same original PDF starts text extraction again. Reader can reuse the text it has already verified and still search the whole document for a different answer.

## What changes

Let the running ordinary Reader reuse derived source material from one unchanged original PDF. Each question still captures its own page and handwriting, selects its own sources and publishes its own answer. The existing researched-PDF setting selects this path.

## Capabilities

- Extend `normalized-source-cache` with process-local reuse by ordinary Reader.

## Impact

This affects original-PDF acquisition and retrieval in Buddy. It needs no new Manager setting, disk format or installation step.
