# Closed consumer contract

Private selectors are exactly export-notebook and inspect-notebook with --archive-input -. Input is exactly {path:string}, <=16384 encoded UTF8 bytes; path is absolute, nonroot, NUL-free scalar text <=4096 bytes. No normalization or interpolation.

Accept exactly one LF-terminated UTF8 report <=16384 bytes and successful exit. Exact fields: report_version=1, operation=requested selector, status, incomplete, activation_performed=false, data. Inspect statuses: ok, invalid-input, unavailable, unsupported. Export also permits busy, failed. Refusal data=null and incomplete=true only for unavailable/failed. Success has incomplete=false and data.inspection exactly format=4, manifests/objects integers 0..4096, selected_scopes=0, selection_receipts=0, complete_media=true, configuration_included:boolean. Reject extras, duplicates, BOM, CR, nonfinite, future versions and trailing frames. Output followed by nonzero exit is unusable even if it resembles success.

Public envelope <=8192 bytes: contract_version/status/observation/notebook_archive. View fields: state/reference/invocation/summary/original_outcome/check_outcome/retained. Actions: retained (no other fields); inspect/prepare-export with connection_id,boot_id,invocation,path; confirm-export/check-export/cancel with connection_id,boot_id,invocation,reference (cancel permits null). Digests are lowercase SHA256-shaped, UUIDs canonical nonnil. Public summaries use only the seven inspection fields. Retained rows are reference/connection_id/boot_id/original_outcome/expired, maximum eight. States ready,inspected,exported,archive-observed,unresolved,unknown,not-dispatched,refused,unsupported,unavailable,busy,capacity,invalid-input,invalidated and retained-only idle. Original outcomes exported,unknown,not-dispatched,refused. A known refused export means the command may have run but no export writes began. Check outcomes archive-observed/unresolved never change the original.

Private envelope <=24576 bytes, canonical bounded base64 input/output; fixed transport verifies wired identity before/after and requires zero exit. Eight original slots, thirty-two invocation entries/original and thirty-two queued fences. Two-minute preview and thirty-minute private original lifetime; expiry never renews or evicts retained safe history. Cancellation targets matching current invocation/owner/epoch/token. No automatic retry, overwrite, staging deletion, format fallback, Store repair or restore.
