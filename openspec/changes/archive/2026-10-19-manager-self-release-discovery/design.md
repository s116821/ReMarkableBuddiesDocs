# Design

Start from accepted Manager3aea /Docsbcb. Keep one controller implementation with a typed fixed stream selector Buddy|Manager and repository-specific URL validation. Preserve old Buddy default API, persisted source preference and poll/cancel/rate-limit behavior. Manager stream has no community/source preference and cannot touch Buddy's saved key. Poll both independently with separate state/abort/backoff; one failed/rate-limited repository does not suppress the other. No arbitrary endpoint supplied by renderer or metadata.

Manager's expected metadata assets are manager-browser.zip, manager-linux-x64.zip, manager-win32-x64.zip and provenance.json from the existing release contract. Uploaded/nonzero/url-correct metadata is availability evidence only, not checksum/signature/provenance/compatibility or update permission. Never treat a development build as older/newer via synthetic version comparison. Current identity comes only from existing generated build-info; candidate from clean stable upstream tag. Show neutral current/latest, published/incomplete/stale/error status and explicit preview/manual-update boundary. No source project version maintained or minted.

Shared Angular/Tailwind panel reuses existing components. Both source check buttons remain separate. Host tests intercept both fixed release APIs before startup and deny unexpected external traffic. Verify initial requests, independent refresh, stable promotion while running, no reload, wrong-repo/pre-release/asset refusal, independent failure/backoff/disposal and browser/Electron/package/narrow layout. Keep existing source preference, tablet gates and public manual setup.

Full self-update delivery, deployment, signed download verification and fullREM41/42/35 lifecycle remain open. Code/spec review and required CI precede any lifecycle action; accepted earlier transport/inspection branches remain frozen. No new worker/worktree or protected Main edit. Existing version-placeholder debt is separately coordinated to REM46 owner; no release-owned file changes in this slice.
