### Requirement: Shared deliberate presence-only saved model editor
Both companions SHALL expose the same explicit model/base_url set/clear editor through fixed protected host adapters under contract.md, preserve exact opaque replacement text and origins/presence, and distinguish saved disk state from runtime/provider readiness.

#### Scenario: Fresh origin-only editor
- **WHEN** an explicit Begin reads original saved declarations
- **THEN** both hosts show only origin/presence and fresh bounded edit authority, never existing strings or a general/basic digest as permission.

#### Scenario: Untouched, explicit replacement or null removal
- **WHEN** the user keeps a field, replaces its exact text or removes a declared-null override
- **THEN** untouched keys are absent, original decoded replacement text is not normalized, clear removes the declaration and producer no-change remains an honest no-write result.

#### Scenario: Saved versus effective behavior
- **WHEN** apply verifies or an original desired file matches
- **THEN** UI shows only that limited saved-state outcome without provider/runtime probes, restart or historical publisher claims.

### Requirement: Bounded private text with hash-only reconciliation
The consumer SHALL retain raw replacements only for the transient renderer draft and bounded one-shot Save, bind the exact original patch privately, and retain only hash-only original evidence after possible dispatch. All safe output/status/diagnostics SHALL exclude arbitrary old/new text.

#### Scenario: Paste, edit and submission lifetime
- **WHEN** replacement contains CRLF, trailing controls, Unicode or credential-like text and is then edited/submitted/cancelled/refreshed
- **THEN** the exact intended raw patch survives deliberate input handling without silent normalization and draft/DOM/Save-only references clear at the specified lifecycle boundary without a false zeroization claim.

#### Scenario: Lost apply and hash-only status
- **WHEN** original apply may have run but its complete reply is unavailable
- **THEN** raw patch is not retained for retry, original intent permits only explicit desired-file status, unresolved has null current and later refusal cannot settle publication uncertainty.

#### Scenario: No response value echo
- **WHEN** any success, refusal, malformed private report or raw child error is handled
- **THEN** old/new values, lengths, endpoint hostnames, hashes and private intent cannot appear in public results/logs or retained UI diagnostics.

The model coordinator SHALL preserve original120s edit authority, one13s Save budget, remaining lower-phase bounds, capacity and all basic/forget ownership guarantees, with generation checks through final publication and every post-await Stop mutation.

- **THEN** shared lane/reference/token custody preserves the new owner, busy performs no I/O/hook/cancel, acquired status invalidates ready and old completion cannot release or settle newer work.
