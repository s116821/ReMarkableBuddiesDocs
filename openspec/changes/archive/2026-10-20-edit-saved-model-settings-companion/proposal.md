# Shared private saved model/endpoint editor

## Why
The delivered producer edits only saved model/base_url, but neither companion has
its explicit origin/presence-only editor. Basic/general inspection cannot grant
that authority. Replacement text may itself contain credentials, so it needs a
separate bounded lifetime and must not become retained status evidence.

## Scope
Add one shared browser/Electron editor and protected fixed modelSettings host
operation for deliberate set/clear of these two declarations. Keep saved strings
opaque and exact; show only origins/presence from the tablet. One Save internally
prepares/applies once using original inspected conditions. Retained unknown status
uses hash-only intent after raw replacement buffers have been released.

No provider call, credential/reference management, runtime/service restart, model
catalog, URL verification, arbitrary Config/path editing, producer change, tablet
contact or general/basic/forget contract expansion. Main's ordinary-export work
and protected live-provider prerequisites retain separate ownership.
