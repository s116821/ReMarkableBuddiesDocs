## Why
The shipped ordinary restore producer has prepare/apply/status and exact guarded additive publication, but Manager lacks the consumer. Users need the same preview, deliberate once-only confirmation and explicit original-state check in browser and Electron.

## What Changes
- Add one protected untrusted on-tablet source draft during Prepare, narrow guarded ordinaryRestore capability, fixed private stdin transport and original intent custody.
- Publish only the closed safe preview/result, preserve original publication evidence independently of Status current state, and share UI/manual behavior across both companions.
- Add a thirteenth shared maintenance owner and preserve all prior132directed relationships.
- Explicitly clarify live ordinary-owned-restore to permit only untrusted Prepare source selection; no renderer intent/hash/generation or Confirm/Status/Cancel source. Historical archives and producer behavior stay unchanged.

## Capabilities
### New Capabilities
- `ordinary-archive-restore-companion`: bounded additive restore and original-only reconciliation in both companions.
### Modified Capabilities
- `ordinary-owned-restore`: explicit host-owned authority and narrowly permitted untrusted Prepare source draft.

## Impact
Manager host/transport/protocol/controller/UI/tests/manual and one paired central Docs change. No Buddy producer, Store writer, SDK, provider, service, native page, release mechanism or dependency change. Independent concrete precode is accepted; source implementation and qualification remain pending. Broader restore/cloud/clean-device/selected/shared/generation4 requirements remain open.
