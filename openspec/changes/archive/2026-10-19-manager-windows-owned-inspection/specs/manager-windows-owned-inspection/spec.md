## ADDED Requirements

### Requirement: Windows inspection reuses accepted wired transport
The development Manager SHALL route parameterless owned-data inspection through the existing repaired Windows wired adapter and shared fixed read-only CLI, preserving USB/session, route, host-key, private-file and notification refusal controls.

#### Scenario: Windows software inspection callback
- **WHEN** an admitted Windows wired transport runs a requested owned-data inspection
- **THEN** it invokes the same bounded inspection callback and returns the same validated report envelope without arbitrary commands or paths

#### Scenario: Timeout or invalidation
- **WHEN** the Windows deadline, cable generation, route or notification invalidates inspection
- **THEN** the result contains no current report and timeout/cancel/session status remains explicit

### Requirement: Host fixture evidence stays distinct from hardware support
Manager SHALL qualify software dispatch and both UI editions independently while keeping real Windows USB and installer qualification explicitly pending.

#### Scenario: Valid fixture and actual config refusal
- **WHEN** shared UI fixtures show a report or the actual Windows interpreter refuses invalid host config
- **THEN** evidence distinguishes those cases and never claims a qualified physical tablet inspection

#### Scenario: Unmerged integration parents
- **WHEN** the integration is reviewed before Windows/inspector/backend parents are delivered
- **THEN** the exact dependencies and open Main hardware/lifecycle gates remain visible and no merge/archive or production support follows
