## Existing boundary
product_settings::apply_with and research_settings::apply use Store::open_existing_for_config, then basic::Custody::acquire and the existing Store::replace_config_document. maintenance::open_existing_for_config selects the existing selected-aware legacy admission, which passes notebook=false into open_existing_using. CURRENT's format4 or any notebook marker therefore refuses before normal recovery. Notebook restore already has a distinct existing-only ready constructor. Product/research raw-preserving target encoders and report schemas need no change.

## One custody and explicit layout policy
Add a narrowly named crate-private preference admission, used only by product/research Apply. Reuse ExistingCustody::open and the common existing-only Store construction/recovery, not a second Store/writer. Preserve the legacy selected-aware boolean behavior for old formats. Use a private closed notebook-admission policy (or equivalent explicit argument) so existing constructors retain Deny, notebook restore retains Require, and the new preference entry permits the ready ordinary notebook case.

Read CURRENT/current-generation format and notebook-marker state after acquiring the existing exclusive OS lease. Require regular supported metadata and definite absence/presence; no path probe before custody, second lock acquisition, or catch-Unsupported fallback. For format4 select strict notebook readiness under that same lease. For old supported formats with no notebook marker use the unchanged selected-aware legacy branch. Old format with notebook marker, unknown/interrupted layout or failed I/O refuses; none falls through to another family. Existing legacy and notebook-restore callers must retain their exact current compatibility/refusal behavior.

## Notebook-only admission
Require existing data/cache/credentials owner identity and matching actor/current generation via ExistingCustody, exact notebook feature/optional marker bindings, contract bytes and published capabilities via notebook_generation::validate_ready, and complete normal recover with index.unavailable==0. Require absent or empty regular directories for selections and selection-history using the same definite existing-file rule as notebook archive custody; nonempty/wrong-type/unreadable paths refuse. Require all recovered manifests to be local transactions and persisted mode to be absent/LocalOnly via existing mode validation; foreign/isolated/shared/corrupt mode refuses. A retained feature marker alone is not permission to enable selected maintenance. No source/ledger/native receipt reinterpretation or live-token creation.

This admission does not call Store::open, initialize roots, publish capabilities, adopt/upgrade a generation, recover staging through a new path or remove interrupted state. It inherits the existing trusted/quiescent local-filesystem model and existing recovery capacities; no hostile uncooperative-filesystem or hard power-loss proof is promised.

## Publication and unchanged callers
After admission both writers acquire existing Custody and call the same byte-exact conditional publisher, retain the report's Arc/ordinary-mode guard through the existing single write_all/error boundary (no flush call), and preserve original config/path/base/target intent validation. Existing product/research patches preserve unrelated raw configuration declarations. Refusal before publication is not-dispatched; possibly attempted failure stays unknown; successful disk readback retains product restart-required / research runtime-unverified, never running activation. Status stays file-only original-target observation and cannot reapply or regrade uncertainty. No notebook data, CURRENT, identity, contract/capabilities or media bytes change during a setting write.

Do not change open_existing_for_config or its other callers' meaning. In particular Linux model credential-file publication, basic/model/memory/credential-reference setters, older whole-typed-config personalization mutation, mode/outbox/archive helpers and native actions retain current notebook refusals. No Manager capability factory/transport/UI change is required: the existing two selectors and strict report shapes stay identical. Broader notebook configuration and actual stopped/restarted device behavior remain separate work.

## Meaningful qualification
Use real committed ordinary records/media, explicit notebook preparation and complete ready format4; capture inventories only after fixture preparation. Run actual product and research inspect/prepare/apply/status paths; verify intended config-only patch, exact readback/reopen and unchanged unrelated declarations plus full data/cache/credential tree/CURRENT/actor/marker/media bytes. Exercise absent and explicit LocalOnly modes and optional feedback/retained-feature markers without actual selected state. Preserve existing real legacy1/2/3 controls.

Refuse active external custody/Busy, wrong owners, malformed/missing readiness/contract/capabilities, old-format notebook marker, unknown format, nonempty/wrong-type selected/history residue, selected manifest, isolated/shared/corrupt mode, stale source config and missing roots without initialization/repair. Explicitly prove old generic config opener and excluded credential/settings callers still refuse the same notebook fixture. Force before-publication and post-publication/lost-readback failures through existing ConfigFault helpers; original unknown stays unknown and Status observes without another Apply. Actual consuming report immediate/prefix write failures must hold custody until completion/failure, then release. Exercise both real CLI selectors with version1 reports/unchanged intents and no environment/provider/runtime startup. Host/CI evidence is not device activation or native qualification.

Use existing author-owned Cargo cache after process/headroom checks, no new dependency or simulator workflow for a configuration-only admission. Preserve first failures and exact source/CI attribution. Finish independent precode/source review, current required checks, canonical sync and finite archival in the same paired PRs. No wider REM42/52/35 closure.
