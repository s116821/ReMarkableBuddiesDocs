# Bounded acceptance plan

| Boundary | Required evidence |
| -- | -- |
| Schema/defaults | Actual current config and source pin; unchanged legacy defaults; strict missing/null/unknown/version/refusal and independent field clear/no-op vectors. |
| Save | Original path/base/change/target CAS; atomic saved readback; corruption/conflict/lost reply; original-only status without automatic replay or runtime claims. |
| Admission | Actual Reader, Writer and export routes before effects; Reader-off/Writer-on; caller-independent policy at every actual Writer entry (automatic Reader delegation remains absent/unclaimed); maintenance re-enable; original unknown export status without new dispatch. |
| Privacy | No raw config/credential/intent/hash leakage; draft/DOM clearing before waits and on Stop, peer, observation, identity, page and expiry; exact context binding. |
| Ownership | Sixteen owners/240 directed grant and Busy pairs preserving prior210; enumerate actual incoming/outgoing App and observation paths. |
| Cancellation | Pending Begin/Save/Status, delayed admission, permanent ready revocation, successor isolation, original unknown history and nonrenewing finite custody. |
| Both hosts | Real browser-helper and Electron source/retained-package flows, safe labels, unsupported/error/unknown distinctions and responsive captures using synthetic inputs. |
| Delivery | Exact code/spec/vector pins; relevant type/lint/build controls; required Windows/Linux hosted artifacts; independent review; scoped sync/parity/archive and actual-main release receipt. |

Native/device/service activation and live provider/account checks are separate,
explicitly unclaimed acceptance unless actually authorized and verified later.
