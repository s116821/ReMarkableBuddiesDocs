## Why
The delivered saved model_credential reference producer has no shared companion consumer. First-use reference setup still requires manual configuration editing even though bounded set/clear already exists. A dedicated saved-only editor removes that prerequisite without implying credential-file installation or authentication.

## What Changes
- Add an optional, guarded credentialReference capability and one shared private-name editor in browser and Electron.
- Keep existing name spelling, declaration origins, producer no-op, original-bound one-shot apply and read-only original reconciliation.
- Compose a seventh maintenance lane with all42 directed pairs, reciprocal private-input clearing and retained uncertainty.

## Capabilities
### New Capabilities
- `saved-credential-reference-companion`: explicit shared saved reference editing, origin/presence-only results and bounded original reconciliation.
### Modified Capabilities
None. Producer, credential-file protocol and all delivered editor wires remain unchanged.

## Impact
Additive Manager protocol/coordinator/fixed Python transport, guarded HTTP/main-frame IPC and shared Angular editor/tests; central Docs alone owns OpenSpec. No dependency, generic maintenance framework, source version, backend/provider, credential-file or device operation. This is an unimplemented precode proposal for one complete paired Docs/Manager delivery, not a planning-only release. Independent exact precode review precedes all Manager API/source edits; current required both-OS source/retained checks precede own sync/archive and final Docs-first delivery.
