## Why

Older component-local and paused planning wording is superseded. Public contributors need a self-contained entry point without private boards, tools or hardware.

## What Changes

- Preserve Rust main canonical specs, archives, config and workflow assets with exact source commit/blob provenance; preserve the unfinished responsive-reader change from da8838db9863d504b12b5e8b44a3015af9ded0cd as active.
- Establish a public repository manifest, task routing, selective portable bootstrap, manual/fork overrides, shared instructions, architecture and roadmap.
- Replace Rust OpenSpec copies with central links in a coordinated Docs and Rust PR set; Manager owns its scoped foundation change and component pointers.
- Verify repeat setup, dirty clone/worktree safety and documentation-only release classification without tablet operations.

None. This migration preserves runtime contracts and unfinished task state verbatim.
