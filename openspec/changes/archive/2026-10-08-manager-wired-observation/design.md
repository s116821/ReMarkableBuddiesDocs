# Design

## Existing contracts and references
Canonical manager-foundation, manager-release-source, manager-vellum-verification and manager-published-arm-apk describe completed bounded slices. Shared storage exposes nonsecret capabilities files and an OS service but no Buddy admin API. Main current handoff (October8) specifies USB parent/interface proof, constrained on-link route/socket, independently verified SSH key, bounded SFTP and cable-loss invalidation. Main supplied its complete prior proposed design and Windows route/socket/SSH plan through Drive; both were read before code. Reuse their proof/order, fixed10.11.99.1:22 endpoint, same-origin helper and unknown package-owner gates. Source-address bind alone is insufficient; Windows IP_UNICAST_IF/USB ancestry remains separately unimplemented/unqualified.

Study reManager b3047fbf12ad51193c5ff05563d2d7d677638c95 app_connection.go and app_device.go: maintained SSH implementation, explicit cancellation/generation protection, bounded connections and observed firmware. Issue75 shows reconnection/credential lifetime hazards; issue83 shows host networking permission differences; issue90 distinguishes long-download bounds from this small-read deadline. RCU's management-plane documentation motivates explicit compatibility and reversible boundaries. Do not copy their Wails/Go/React architecture or automatic reconnect/OS/package operations.

## Host and authentication
Linux uses Python3.10+ and pinned Paramiko5.0.0 supplied in a user-owned virtual environment; no global install/bundled interpreter. A fixed helper script owns socket creation with SO_BINDTODEVICE and explicit source address. Before connection, inspect sysfs USB parent and selected interface generation/driver/carrier and both ordinary and constrained IPv4 route; reject gateway routes, mismatched device/source and non-USB targets. Config explicitly selects interface, USB physical parent path/vendor/product, fixed10.11.99.1:22 endpoint, source address, root username, independently verified public host-key SHA256 and selected private-key file. Config parent0700/file0600 and key owner/private regular-file checks; no auto-learning keys or credentials, no password retry/fallback, no key material in argv/log/UI. Missing/encrypted/invalid authentication is explicit. USB serial is not universally present; physical port plus interface generation and SSH cryptographic identity are required instead of IPalone.

One operation has an absolute12second deadline with per-connect/channel/read bounds, total64KiB output ceiling, fixed file allowlist and one fixed OS-state command. The fixed sysfs model attribute may report a synthetic4096byte size; only that known attribute accepts bounded content shorter than its reported size. The OS metadata alias accepts only the explicit /usr/lib/os-release target with before/after link/target checks; arbitrary remote symlinks remain refused. A netlink link/address/route watcher with bounded periodic rechecks revalidates local USB/route identity during operations and closes the socket on change. Node supervisor limits process output/time and cancels the owned child; no SSH forwarding, shell UI or uploads. Host state schema contract_version1 is independent of application tag versions. Return only sanitized enumerated fields and observations; do not export raw diagnostics/config/credentials. Firmware/model/architecture are observations, not compatibility qualification. Absent Buddy unit/capabilities do not prove no files installed; provenance and installed version stay unknown.

## Shared UI and ownership
A shared controller calls observe/cancel, clears prior observations while checking and rejects superseded results. After an explicit connect it polls bounded observations; a failed check or changed boot/interface identity stops polling and requires explicit reconnect. Disconnect cancels and clears all state. Electron exposes only these two IPC calls from its owned top-level renderer. The helper binds127.0.0.1 on an ephemeral port, serves only the built Angular UI, and uses same-origin/Host checks, an HttpOnly SameSite=Strict random session cookie, no CORS, frame denial and fixed JSON actions. Configuration/authentication belong to the local host process. Remote deployed browser shows helper setup boundary; never probes arbitrary localhost addresses or accepts target/command/key parameters from renderer.

## Verification and limits
Hermetic target fixtures exercise route/USB/key refusal before authentication, bounded reads, deadline/cancellation, changed identity and stale result suppression, plus browser-helper origin/host/action refusal. Actual shared browser/helper and Electron integration render observed fixtures while preserving renderer isolation. Authorized Linux RM1 read-only run after fresh ownership/device policy checks identifies exact source/runtime/configured public pin and observation without leaking secrets. Native cable removal and Windows binding are not claimed by fixtures. No full REM-41 installer completion, Vellum trust/package mutation or app version source fields follow.
