## Public capability and exact requests
Optional `sourceCacheCleanup(request)`, guarded POST `/manager-source-cache-cleanup`, main-frame IPC `manager:sourceCacheCleanup`, class SourceCacheCleanupHost, owner/raw observer action `source-cache-cleanup`, helper `source_cache_cleanup_transport.py`, private key `source_cache_cleanup_raw`. One argument. No broad raw API/old allowlist change.

Closed public request union, cap384 canonical UTF8 bytes (HTTP original bytes also384):
- prepare `{action:"prepare",connection_id:CONNECTION,boot_id:BOOT,document:DOCUMENT,invocation:INV}`;
- confirm `{action:"confirm",connection_id:CONNECTION,boot_id:BOOT,reference:REF,invocation:INV}`;
- status `{action:"status",connection_id:CONNECTION,boot_id:BOOT,reference:REF,invocation:INV}`;
- cancel `{action:"cancel",reference:REF,invocation:INV}`;
- retained `{action:"retained"}`.
CONNECTION and REF are exactly64 lowercase hex; BOOT/DOCUMENT/INV are canonical lowercase hyphenated36-byte nonnil UUIDs. REF is independent cryptographic256-bit randomness, never a digest of content or cross-lane authority. No normalization/trim/case coercion, unknown/duplicate fields, arrays, unsafe scalar Unicode, cyclic/BigInt, document/path/operation UUID on confirm/status, intent/hash/budget/selector/Config/value in other actions. Document is explicit non-authorizing public metadata, not content. INV is a fresh cryptographically random client-minted UUID for each prepare/confirm/status invocation, captured before its first pause/transport await and never reused for a later invocation. It is a routing nonce, not the independent host-minted producer operation UUID or a mutation credential. Renderer Stop captures the intended `{reference,invocation}` tuple BEFORE queuing cancel; never look up the then-current invocation after a local timeout or inside a delayed callback. Both adapters preserve that exact tuple without substituting current state. No INV appears in remote stdin/command or producer intent.
