## Why

The Manager can search existing memory but cannot show the saved storage mode that
governs its local or selected data. The new one-shot inspection contract permits
both companions to display that metadata without exposing mode-changing authority.

## What Changes

- Add an explicit Saved storage mode inspection in browser and Electron using the existing identity-verified wired adapters.
- Validate the bounded inspect-only report, preserve truthful refusal states and return a reduced view without conditional write tokens or provider binding/root details.
- Distinguish unconfigured legacy policy, saved LocalOnly, isolated backup and shared group from running service or sync/provider readiness.
- Clear results on cancellation, replacement and session changes; retain public setup/manual guidance and separately attributed backend, transport and UI evidence.

## Capabilities

### New Capabilities

- `manager-saved-mode-inspection`: Shared read-only inspection of saved mode metadata with bounded host authority, truthful status and session-bound results.

### Modified Capabilities

None. The existing foundation permits separately specified narrow capabilities;
memory search, mode choice and their backend semantics remain unchanged.

## Impact

Manager host parser/transport, shared Angular controller/view, browser helper and
Electron capability bridges, focused tests and existing platform integration jobs.
Central OpenSpec remains in Docs. Main owns the Rust mode CLI, Store/configuration,
ordinary runtime guards and its separate paired delivery. No new dependency,
source version, service/API, provider operation, native action or tablet access is
required. One linked Docs/Manager delivery retains implementation, verification,
canonical synchronization, archival and final review together.
