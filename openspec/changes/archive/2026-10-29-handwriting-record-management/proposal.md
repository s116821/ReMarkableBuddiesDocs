# Inspect and deliberately remove saved handwriting corrections

## Why
Confirmed handwriting records already support explicit query, inspection and CAS tombstones, but the browser and Electron companions do not expose their management. Users need to examine an incorrect saved correction and deliberately remove it from active use without being told historical samples were erased or recognition improved.

## What changes
- One shared saved-corrections panel with explicit profile selection, bounded text search, exact-key inspection and separately confirmed removal from active use.
- Fixed wired `--handwriting` consumer for query/inspect/forget/status only, with strict private report validation, captured-head confirmation, once-only dispatch and retained original-operation status checks.
- Finite private custody, identity and lifetime guards, shared maintenance ownership, browser/Electron parity, public manual and concrete host/transport/UI qualification.

## Scope and non-goals
One coordinated Manager/central Docs delivery includes precode review, implementation, qualification, canonical sync and archival. It is not a planning-only merge. The existing producer is unchanged. No new confirmation/sample upload, correction editing, multi-head conflict resolution, sample image display, secure erasure, automatic recognition hooks, training, efficacy claim, provider/native/selected-sync activation or tablet qualification is introduced. Profile IDs are explicit logical groupings, not discovered people/accounts. Existing personalization and subject memory remain distinct. Versions remain tag-derived at build time; no maintained source version is added.

## Impact and authority
The central change defines the new companion consumer; the existing confirmed-handwriting-records capability and its delivered v1 contract remain authoritative for the producer. Only owned Manager and central Docs paths change. Source audit and unresolved fresh-source/base transfer are recorded in source-proof.json. Implementation waits for independent review of this concrete proposal/contract/acceptance packet. Whole Manager, handwriting, sync and 1.0 acceptance remain open.
