# Typed catalog boundary
Consume Main immutable OutcomeFact/AttemptReason types only. New conversation_feedback module and integration tests plus one library registration; no domain, journal, store, LLM, orchestrator or admission changes. Description includes original historical identity, stable code and static concise message. It is not a new outcome fact or current render permission.

Reject nil identity and non-feedback states; Completed yields no error description. Uncertain reasons and ReconcileRequired take precedence over canceled/failed labels and never promise output was undone or delivered. Ordinary cancellation describes the recorded request only. Static catalog is independent of raw logs, credentials, request/output text, firmware and SDK adapter identity. Native header/error-turn insertion and pre-page pending persistence require later owned-state/current admission integration. Responsive cancellation and the known scoped blocking HTTP join delay remain unimplemented; no guessed timeout/sleep is introduced. Live/provider/native/simulator lifecycle evidence remains separate.
