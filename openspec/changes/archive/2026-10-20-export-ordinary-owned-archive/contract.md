# Ordinary owned-export producer v1

## Entry and caps
Use --ordinary-export-operation prepare|apply|status with exact --ordinary-export-input -. No file fallback, missing/default config, runtime/other maintenance flags, dotenv, provider or service initialization. REMARKABLE_BUDDIES_CONFIG names one explicit absolute existing config for prepare/apply only; status does not read it. EOF-delimited strict UTF8 JSON input and single-LF complete report each cap16384 bytes including whitespace/LF; active config and optional stored snapshot each cap1048576. Preserve existing host deadlines. Exact object shapes/recursive duplicate and unknown refusal; no record arrays/coercion/null except explicitly nullable snapshot digest.

Use original ordinary restore bounds:4096 manifests/objects,8388608 archive/manifest/unique record metadata bytes,268435456 per media object and existing bounded streaming/copy checks. SHA hashes are lowercase64hex; UUIDs non-nil; versions exact1. All counts fit safe bounded integers. Old archive/restore/basic/general wire, limits, legacy callers and other source ownership are unchanged.

Full strict original config/schema/value/path validation; sync.enabled:false; existing ordinary format1 Store in unconfigured/local-only mode only. Refuse selected format/feature/metadata or shared/isolated/unsupported/corrupt/unavailable state. Never initialize/repair/retarget/replay. Under one existing mutex capture current actor/mode token/generation/full history and optional stored config snapshot. ## Apply, same writer, and phase
Apply exact input `{destination:ABS,intent:INTENT}`. Validate exact original path/hash/config/actor/mode/generation/full-history/raw snapshot/desired archive/completeness under original live custody and same Store mutex. Same-generation commit, snapshot whitespace changes and mode changes conflict without refreshed conditions. Recompute target before exclusively creating the previously absent destination; target/condition mismatch refuses before copy. Refuse all root/case/canonical/reparse/occupied/race hazards without altering competitor/source. Reuse SAME existing export object-copy/atomic backup.json writer, never an independent archive serializer/writer or selected activation path.

After exclusive reservation, failed copying before atomic backup.json attempt is failed/not-published; partial destination may remain. Once atomic backup.json is attempted, any failure or changed readback is failed/unknown; destination/source remain for observation, no retry/delete/rollback. Complete verified apply requires exact original target marker hash and fully verified format1 closure/lineage/object completeness readback. Keep OS Store/mode custody through one fully encoded/bounded consuming output attempt; prefix failure emits no second report.

## Pure status
Status exact input `{destination:ABS,intent:INTENT}`; no source/config/Store/declared-root/mode/credential/provider read or write. Compare original destination spelling/hash and safe destination path, bounded marker bytes/original archive hash, exact format1 policy and verified complete closure/completeness. A current complete match reports desired-archive-observed; absent marker, valid different marker or incomplete/invalid closure is unresolved with null DATA. A read/admission refusal reports its honest read-only status and cannot settle original uncertainty. Never infer original publisher identity, complete historical apply, a Store admission, runtime activation or deletion permission. Archive config is validation-only, never installed or resolved.
