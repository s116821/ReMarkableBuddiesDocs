## Why
Manager can inspect one deliberately selected fact but has no safe bounded removal contract. A bare stdin bridge to file Forget would freshly bind config/mode and could act on a different accepted selection with identical Key/head IDs. A historical receipt is not current deletion.

## What Changes
- Propose bounded read-only preparation and receipt reconciliation plus explicit one-fact confirmation over stdin, with original mode/config/store/selected acceptance preconditions.
- Keep acknowledgement historical, uncertainty explicit and original file behavior unchanged; refuse ambiguous previews and all unrelated mutation/setup selectors.
- Publish exact producer/consumer protocol before source implementation and coordinate both Manager hosts separately.

## Impact
Host memory maintenance and central host-memory-cli requirements. This active change is implemented in the unmerged source candidate; it is not yet delivered behavior or device authority. It does not implement an editor, purge, generic write API, provider worker or native document deletion.
