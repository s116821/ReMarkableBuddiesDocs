# Manage the already declared model credential file

## Why
Actual Buddy `7f07169faef2a2e5ec6761412034c012cc37d9f4` can resolve CLI, environment or one protected-reference file but has no bounded credential-file maintenance command. Credential installation/replacement/removal is a required companion capability. A source producer must precede a separately reviewed browser/Electron consumer.

## Scope
Deliberately install a missing file, replace a present file or remove a present file only at the existing saved `model_credential` reference under the existing known credentials root. No filename choice, Config/reference edit, new credential store, directory initialization, environment lookup, provider call, service restart or effective-authentication claim. Missing reference refuses. Preserve exact accepted UTF8 bytes and existing private permissions; do not normalize pasted CRLF/trailing text. Current Store/mode custody and original config/path/absence-or-content/metadata conditions bind one apply.

Concrete design must treat secret-derived fingerprints as confidential, not nonsecret hashes. Conditional evidence and raw replacement text are private host input/output; no renderer/log projection is implied. The existing general/model/memory settings protocols are unchanged.
