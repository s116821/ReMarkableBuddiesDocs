# Selected Writer memory: proposed receiving contract

Status: proposal for Root review only. No implementation, provider execution,
delivery claim or change to the accepted ordinary snapshot contract.

## Basis and smallest useful scope

The ordinary Writer at Buddy b8cc818 has independently qualified optional local
memory and fresh preparation/finish CAS. It deliberately refuses selected
enrichment. The reviewed Reader composition at Buddy 550805a supplies the exact
joined-admission precedent, not an implemented selected Writer receiver.
Preserve those separate source/evidence identities during reconciliation.

Propose selected supplied-text Generate and Refine only, with optional selected
memory and no native output or export. Reuse the existing conversation, source
and draft identities; do not create another registry or Store. Ordinary commands
and memory-disabled ordinary behavior remain unchanged. Selected mode must enter
an explicit receiving path; never retry through ordinary Ledger writes or local
memory on refusal. Do not broaden this increment to notebook map/reduce,
recognition, export preparation, destination calls, native pages or sync recovery.

## Writer selection and preparation

Require an exact acknowledged Writer conversation selection: same receiving
Store, group/binding, document scope, accepted SelectionToken and exact root,
source and (for Refine) generated-draft references. Validate ownership and the
complete selected projection and source bytes. A restored binding is historical
metadata, never physical authority. Memory profile/catalog membership remains
distinct from Writer document scope and cannot choose the Writer conversation.

Introduce a selected Writer preparation record/receipt using existing selected
publication infrastructure. It must validate the exact accepted selection,
persist the verbatim user request and immutable normalized source/reference,
and return the acknowledged post-preparation token/root/user/source/draft
references. Refine must pin the selected draft and its actual source/history,
not copy text from an arbitrary ordinary record. Preserve request fingerprints,
deterministic stage IDs, correction links and current chronological context.

Fresh preparation alone admits model work. Historical acknowledgment/replay
must recover its exact result or report interrupted/unresolved state without
another model call. Missing source/media, replacement, foreign ownership,
incomplete history or unresolved commit refuses before model. Failed/canceled
records, if published, must use the selected boundary too; no ordinary fallback.

## Memory retrieval and actual consuming publication

After fresh selected Writer preparation, query from the exact new request and
immutable source document, preserving existing 2048-byte query, eight-match and
8192-byte encoded-context bounds. Keep source/history, saved preference and
author-asserted associative data separate. Current request/source win. Empty
usable results add no part; unavailable, unusable Partial, invalid or over-budget
results fail closed without a model or silent fallback. Memory disabled means
no provider construction/query; selected Writer still uses its own guard.

Reuse the reviewed SelectedMemory result-instance/payload digest, catalog and
queried-aggregate tokens/raw heads, cumulative SelectedReadBudget and consumed
flag. Add an explicit selected Writer provider admission/publication seam;
Provider's ordinary compatibility callback is insufficient. Admission requires
the same Store/group/binding as the Writer, while preserving catalog/profile
identity and independent aggregate ownership checks.

At actual Generated publication, hold one complete deterministically ordered
admission set: Writer scope plus memory catalog and every queried aggregate.
Use SelectedAdmission::with_gates once, following
SelectedAdmission::publish_reader_text_joined and
SelectedMemory::publish_selected_reader_text. Do not nest/reacquire participating
admissions or invoke ordinary finish_writer inside Provider::with_current.
Under that set, recover any exact historical receipt first; otherwise validate
the post-preparation Writer token/exact references, complete source/history and
the original memory result pins/digest/budget, then commit selected root/draft/
receipt atomically through commit_selected. Do not write a stale draft before
the join. A fresh publication attempt consumes its memory view even on refusal,
failure or panic; historical recovery does not reconsume it or grant an effect.

Return distinct Published and Historical results, following the Reader shape.
Failed/lost acknowledgment reconciles only from preserved exact selected
receipts; no model rerun or automatic retry. Historical/replayed results grant
no fresh WriterSelection/native/export capability. Any future selected export
consumer needs its own reviewed acknowledgment/authority contract. The stronger
selected publication check does not retroactively strengthen ordinary local
snapshot freshness, which remains explicitly non-atomic across model I/O.

## Focused acceptance before implementation/delivery

- Root first reviews the selected preparation/finish types, ownership projection,
  historical recovery and failure disposition against actual reconciled heads.
- Actual Store controls cover Generate and reopened Refine, exact source/history/
  correction references, optional empty/disabled memory and usable Partial.
- Catalog, queried global/document aggregate, Writer root/source/draft and
  membership replacement each invalidate publication. Unrelated scopes remain
  intact; duplicate/opposing admission sets complete without deadlock.
- Foreign Store/group/binding/profile, tampered result, consumed view, missing
  media, cumulative-budget exhaustion and selected/ordinary mismatch refuse.
- Cancellation, before/after-commit failure, lost acknowledgment, replay and panic
  retain exact receipts, prevent duplicate drafts/model calls and never create
  native/export authority. Include witness controls at the real selected commit.
- Preserve ordinary 32-test/live evidence attribution; new source requires its
  own focused checks and hosted qualification. Additional representative model
  work requires a separately reviewed exact plan; this proposal adds no calls.
