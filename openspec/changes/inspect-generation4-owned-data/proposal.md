# Why

The merged notebook generation4 contract retains Source3 archived normalized
sources and Conversation3 plan/stage facts. The existing owned-data observer
supports formats1/2/3 only. Its report1/2 refusal is truthful; treating4 as3 or
changing a released report enum would conceal unsupported accounting.

# What changes

- Add an explicit read-only `--inspect-owned-data-v3` route and separate report3,
  leaving the existing selector and report1/2 behavior unchanged.
- Account supported generation1/2/3/4 metadata, notebook record kinds and their
  descriptor-referenced media without Store startup/recovery, archived-media/original-document reads,
  provider access, storage adoption or cleanup authority.
- Define one closed successor contract for the browser and Electron hosts, with
  exact unsigned-decimal counters, truthful partial/unknown totals and existing
  connection/boot/cancellation/privacy fences.
- Deliver producer, both Manager consumers and this central change as coordinated
  linked PRs. No planning-only merge or premature archival.

# Scope and delivery

This is precode, not implemented support. Publish and independently review the
producer/consumer contract before shared implementation changes. Deliver the
producer, both Manager hosts and this central change as linked coordinated PRs;
keep independent release compatibility and unsupported older installations
explicit. Public requirements and source references suffice for contributors.
