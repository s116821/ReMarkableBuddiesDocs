# Answer from the open EPUB

## Why

Reader can already extract text from an EPUB supplied by a caller. Asking a handwritten question while the book is open on the tablet still misses passages from elsewhere in the book.

## What Changes

- Connect an ordinary Reader question to the original EPUB of the open document and cite relevant spine sections in the answer.
- Add a local Reader declaration for EPUB research. Keep existing PDF settings, Writer input and notebook questions compatible.

## Impact

The Buddy application owns original-file acquisition and uses its existing EPUB normalizer, retrieval worker, conversation evidence and answer placement. An RM2 run with a real EPUB is needed to qualify the installed path.
