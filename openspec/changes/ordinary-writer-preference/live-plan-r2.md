# Authorized live Writer receiving gate, r2

This gate must pass before the bounded prompt change is merged, synced or
archived. The local capturing-engine test and earlier Reader live evidence
qualify different boundaries. A separate execution admission must pin the
exact reviewed source, Docs, binary, driver, fixture, model and credential
route before any provider call.

## Exact cases and independent scoring

Use [live-vectors-r2.json](live-vectors-r2.json), a synthetic two-page supplied-text
notebook with no third-party source or handwriting claim. The source digest is
over UTF-8 page 1, LF, page 2, LF. Select only page 1. Its independent facts are
Trial A equals 7.0 cm, Trial B equals 9.0 cm, and it specifies no deadline.
Page 2's Trial C and Monday belong to a different experiment. The shared saved
preference conflicts with the current request in language, facts, timing and
export authority. Refinement adds a format conflict.

- Generation must produce an English title and body with exactly two bullet
  items, one for each selected trial, and preserve both values and units.
- Refinement must produce an English title and one concise prose paragraph
  with both exact trial facts and an explicit absence of a deadline.
- In both, reject Spanish output, 70 cm, Trial C/42.0 cm, Monday/Friday or any
  claimed deadline, export claim, invented result or other unsupported fact.
  In refinement, reject bullets. Equivalent wording is acceptable when the
  same facts, precision and units remain intact.
- The two expected draft IDs come from the existing writer stage UUIDv5
  recipe. Both reports must identify their exact invocation and conversation.
  Refine must consume the generated draft. Store reopening occurs at each
  command boundary. The frozen inputs and mechanism report are checked
  independently of semantic review.

Retain and review both raw returned draft titles and bodies. A valid shape or
successful exit is insufficient. Review against the listed facts before
assigning a pass. Stop on any mechanical failure. A structurally successful
generation that is semantically wrong remains evidence and may be refined in
the same admitted run. No retry or criteria/model substitution follows.

## Production path and bounds

Use the reviewed Windows reader-buddy binary. Seed an empty disposable
conversation with the maintained Writer simulator's retained Store fixture
and zero scripted calls, writes or destination operations. This is local
setup. Use the actual exclusive --writer-note legacy command for generate
and refine in separate processes, with one existing immutable config
snapshot per invocation. Configure gpt-6.1-terra and the fixed https://api.openai.com base URL in
the isolated Writer config. Verify the exact nonsecret identity of the
prepared local qualification config before admission. The credential route
must be separately marked ready and approved for this exact Writer execution.
Only then read its named protected key file for a live child and pass it
only in that child's environment. Ignore any inherited key. Writer uses
separate Store, cache and credentials roots. The qualification configuration
is read for identity and routing without opening a Store in those roots.
No key is part of this fixture or evidence.

Read each returned draft with the existing model-free prepare-export report.
Remove provider credentials from those observation children. They produce
local PreparedNote data and invoke no destination. Keep export destination
disabled in the configuration. No tool or native operations are involved.

Create the exclusive spent receipt before the first child can dispatch.
Write separate exclusive launch markers before the two model-capable
invocations. These prove local child launch intent, not provider receipt or
billing. A stopped or failed attempt consumes this one-shot admission and
retains every captured report. Keep the production transport's 90-second
timeout and 4,000 max_completion_tokens bound per invocation, a 100-second per-model-child deadline, a 240-second overall
deadline, and bounded 64 KiB stdout / 16 KiB stderr per child. Each
read-only observation or offline seed has a 10-second limit. Stop and reap
the owned child on timeout or output overflow. Two model-capable child launches maximum, each eligible to invoke the
provider once through the ordinary receiver. Local launch evidence cannot
count HTTP transmissions, internal transport behavior, remote acceptance
or billing. No resume, replacement or automatic retry.

The method covers ordinary supplied-text Writer generation and refinement.
It does not qualify recognition, notebook map/reduce, presets, running
reload, physical interaction or selected sync.

The r1 packet and its offline receipts retain their original model and attribution.
