## ADDED Requirements

### Requirement: Explicit complete notebook archive controls
Both companions SHALL expose deliberate inspection and policy-previewed once-only export through the existing explicit notebook selectors, with closed format-4 complete-media summaries and optional configuration-presence reporting. Legacy archive behavior SHALL remain unchanged.

#### Scenario: Complete archive observed
- **WHEN** a matching bounded report is received with successful exit and current wired identity
- **THEN** the companion reports complete archive closure without runtime, native, restore or off-device durability claims.

#### Scenario: Unsupported or failed output
- **WHEN** a frame is malformed, unsupported, incomplete or followed by a nonzero exit
- **THEN** it grants no success or fallback; a possibly dispatched export remains unknown unless an exact producer refusal establishes no export writes began.

### Requirement: Bounded immutable original custody
The host SHALL keep exact paths private, consume each preview at most once, bound retention/cancellation/deadlines, preserve original outcomes, and never retry, overwrite or clean an interrupted export automatically.

#### Scenario: Check an earlier unknown export
- **WHEN** a user deliberately checks an unexpired host-held original folder
- **THEN** only present detached closure is reported and the original outcome remains unchanged.

#### Scenario: Late or cancelled invocation
- **WHEN** identity, lifetime, epoch or maintenance ownership changes
- **THEN** late work cannot dispatch or publish, cancellation cannot affect a newer owner, and private drafts/previews clear.

### Requirement: Shared maintenance and private interface
Both host factories and the shared renderer SHALL use the existing maintenance lease and reciprocal peer invalidation. Paths SHALL be exact scalar text, bounded, cleared before waiting, and absent from reports/logs/persistence. The UI SHALL state optional saved-settings inclusion, credential/native-document exclusion and on-tablet archive location.

#### Scenario: Another maintenance operation owns the host
- **WHEN** a peer is active or its review is replaced
- **THEN** conflicting archive actions are refused or invalidated consistently in both hosts, without enabling native Stop.
